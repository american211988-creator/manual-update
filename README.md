# 내규/매뉴얼 변경대비 업데이트 (Hana Life 심사부 PoC)

사무처리기준·업무매뉴얼·내규의 신구 버전을 올리면 문서유형을 분류하고, 조항 단위로 비교해
변경대비표(조항 | 현행 | 개정 | 변경유형 | 비고)를 만들고, 구독 담당자에게 화면 내 알림을 남기는 웹앱입니다.
모든 데이터는 가상입니다.

## 실행

`public/index.html`을 브라우저로 여세요. 서버 설치가 필요 없고, 처음 열면 샘플 3세트를 자동으로 비교해 둡니다.
(.docx·.pdf 읽기만 CDN 라이브러리를 씁니다. .xlsx는 첫 번째 시트를 읽으며 '조항 | 제목 | 내용' 열 구성을 인식합니다. 엑셀·워드 내려받기는 인터넷 없이도 동작합니다. 스캔 이미지 PDF는 읽지 못합니다.)

## Vercel 배포

빌드 단계 없이 `public/` 폴더를 정적 사이트로 배포합니다 (`vercel.json` 참고).
Vercel에서 이 저장소를 Import하면 설정을 따로 바꿀 필요가 없습니다. 루트(`/`)에서 앱이 열립니다.
`public/index.html`은 커밋된 빌드 결과이므로, 소스나 데이터를 고친 뒤에는 반드시 `python3 tools/build.py`를 실행하고 커밋하세요.

## 화면 구성

| 탭 | 하는 일 | 기획서 규칙 |
|---|---|---|
| 문서함·분류 | .txt/.docx/.pdf/.xlsx 업로드, 키워드로 문서유형 판정, 같은 문서의 버전끼리 신구 쌍 자동 묶음 | 키워드 없으면 `미분류` |
| 변경대비표 | `제N조`/`제N조의M` 단위 비교, 바뀐 단어 강조, 비고 자동 작성·수정, 통합 정리본, 엑셀(받은 양식 서식 그대로)·워드(.docx) 내려받기 | 신버전에만 → 신설, 구버전에만 → 삭제, 문구 다름 → 개정 |
| 정답 검증 | `expected_changes.csv`와 건별 대조 (일치/누락/오탐/유형·내용 불일치) | 정확도 90% 이상이면 목표 충족 |
| 알림함 | 문서유형을 구독한 담당자별 알림 메일 본문 (실제 발송 없음) | `users.csv`의 `subscribed_types` |
| 집계 | 연도별 요약표·월별 변경 이력표(과거 개정 이력 포함), 문서별 변경률, 절감 시간 계산 | 변경률 = 변경 조항 ÷ 전체 조항 × 100 |
| 기준 데이터 | 담당자·키워드·정답표·문서 메타 확인, CSV로 교체 | |

## 개인정보 차단

다음 작업 전에 개인정보를 검사하고, 하나라도 탐지되면 작업을 중단합니다. 탐지 내용은 가림 처리해 안내창에 보여주며 원문은 저장하지 않습니다.

- 문서 업로드: 한 파일이라도 걸리면 그 업로드 전체를 반영하지 않음
- CSV 교체, 신구 비교 실행, 변경대비표 비고 입력

탐지 항목: 주민등록번호·외국인등록번호, 카드번호(Luhn 검증), 운전면허번호, 휴대전화·유선전화번호, 계좌번호(‘계좌·입금·송금’ 문맥), 여권번호(‘여권’ 문맥), 이메일 주소.
담당자 CSV의 이메일 열과 `example.com` 같은 예시 도메인은 예외입니다.
시연용으로 `data/pii_test/개인정보_포함_샘플_v1.0.txt`(가짜 값)를 올리면 업로드가 차단됩니다.

## 시험용 더미데이터 묶음 (`data/test_pack/`)

조항이 많고 변경이 많은 문서로 앱을 시험할 때 씁니다. 이미지(흐름도·도표·차트·로고)와 표가 들어간 Word·PDF 문서입니다.

- 언더라이팅 업무매뉴얼 v3.0→v4.0 (.docx, 28개 조항, 변경 16건)
- 보험금 지급 사무처리기준 v2.1→v3.0 (.pdf, 26개 조항, 변경 14건)
- 계약심사 전결 내규 v1.5→v2.0 (.docx, 24개 조항, 변경 12건, 표 안 금액 변경 포함)
- 스캔본 예시 PDF (글자 없는 이미지 → 업로드 제외 안내가 나와야 정상)
- 정답표 `expected_changes_testpack.csv` 42건, 문서 메타 `documents_testpack.csv`

넣는 순서: 기준 데이터 탭에서 두 CSV를 올림 → 문서 7개를 문서함에 끌어다 놓기 → 전체 신구 비교 실행 → 정답 검증 탭에서 42건 일치 확인.
다시 만들기: `pip install python-docx` 후 `python3 tools/make_test_pack.py` (LibreOffice 필요)

## 시험용 더미데이터 2차 묶음 (`data/test_pack2/`)

형식별 신구 문서 1쌍씩: PDF(보험계약 유지관리 업무매뉴얼), Word(모집질서 준수 내규), Excel(보험료 수납 사무처리기준), Text(심사위원회 운영규정).

다시 만들기: `python3 tools/make_test_pack2.py`

## 폴더

- `data/` : 더미 데이터 원본 (신구 문서 3쌍 + 회의록, 정답표, 담당자, 키워드, 메일 샘플, 대비표 양식, 과거 개정 이력 `change_history.csv`)
- `app/src.html` : 앱 소스
- `public/index.html` : 빌드 결과 (샘플 데이터 포함). `data/`나 `app/src.html`을 고치면 `python3 tools/build.py`로 다시 만들어 함께 커밋하세요.
- `vercel.json` : Vercel 배포 설정
